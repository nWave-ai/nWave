# Public PR Sync — Sensitive File Denylist
# =============================================================================
#
# Block pr-mirror/<N> push if a public PR's diff touches any of these paths.
# Patterns are gitignore-style globs (fnmatch against repo-root-relative paths).
# A line starting with `#` is a comment; blank lines ignored.
#
# Supported rule forms:
#   - exact      path/to/file   matches that path only
#   - recursive  dir/**         matches anything under dir/ at any depth
# Trailing-slash directory rules (foo/) are NOT supported — they match nothing.
# Use foo/** instead. See _rule_matches_path in scripts/sync/check_denylist.py.
#
# Review cadence: quarterly. Start narrow, expand only on incidents.
# Source of truth: this file. Consumed by scripts/sync/check_denylist.py.
#
# NOTE for distiller/implementer: This file covers path-glob rules ONLY.
# There is ALSO a content-based rule — see wave-decisions.md §2 "Known
# content-based rule". The script must additionally flag files containing
# rewritten `raw.githubusercontent.com/nWave-ai/nWave/main` URLs,
# reported as `{"path": "...", "rule": "content:rewritten-raw-url"}`.
# BDD scenarios MUST cover both modes.
# =============================================================================
