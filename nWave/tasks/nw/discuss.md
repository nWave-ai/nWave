# NW-DISCUSS

Read `nw-discuss`; it owns conversation and orchestration guidance.
Use nwdes as the delivery route: read `nw-nwdes`, create a feature with
`nwdes feature new` when needed and build the installed `nw-product-owner` prompt
with `nwdes prompt`. The PO uses Bash and `nwdes product` recording verbs
to record promises, scope, decisions, journeys and slices, then closes authority.
The host renders the current brief with `nwdes document`; human corrections
return to the PO's CLI verbs. The host never hand-authors delivery state or copies
a role reply into authority. Successor-wave selection remains LLM-owned.
