# NW-DELIVER

Load `nw-nwdes` and use nwdes as the delivery route. The host chooses the next
supported operation; nwdes keeps no workflow state. Invoke the native installed
Product Owner first with its generated prompt; it records product values with
`nwdes product` record edits and `nwdes product close`.
Every role records through its kind's nwdes CLI verbs using Bash and closes.
The host writes no JSON and copies no reply into another command. For each role
the route invokes, it passes that role's generated `nwdes prompt` bundle verbatim,
and that role, not the host, runs its kind's verbs. Facts the route assigns to the
host, such as `feature new` and `slice set`, stay with the host.
Run every nwdes command from the checkout's top level; roots default to cwd and
the repository root, and lane verbs resolve the main worktree. The first add,
set or remove creates the draft. Use `open --from-current` to revise current
authority; close with no draft validates empty values.

For an uncertain boundary, use the existing delegations to exercise an early
concrete producer-to-consumer connection: semantic input through the nwdes
builder, an executable public-port oracle and RED observation, then its
implementation and observation. If the consumer cannot proceed, return its
specific missing semantic question and counterexample to the owning author
before expanding the affected design or solution. This does not create a
mandatory sequence, controller, or mini-cycle for internal technical fragments.

Role recording verbs and supported invocations: `nw-role-invocation` (never a
generic persona). The architect records design values; the acceptance designer
records acceptance rows for its assigned slice. The crafter records files
and commands with craft verbs; the reviewer records findings with review verbs.
The host runs declared verification commands and observes actual results.
It independently invokes reviewer and public-perspective examiner from prepared
role inputs. The examiner records expectations with `nwdes expectations` verbs
and verdicts with `nwdes examine` verbs through the same CLI.
No command chooses the next role; the host directs operations using `nw-auto`.
