# Commands

| Command | Description | Agents | Arguments |
| --- | --- | --- | --- |
| `/nw-buddy` | nWave concierge — ask any question about methodology, project state, commands, migration, or troubleshooting. Read-only, contextual answers. | [nw-nwave-buddy](../agents/nw-nwave-buddy.md) | [question] - Example: \"What should I do next for rate-limiting?\ |
| `/nw-bugfix` | Routes one observed defect Request through nwdes delivery. |  | [observed defect] |
| `/nw-deliver` | Routes one strict Request through nwdes product and design construction, design facts, public oracle, craft, independent whole-diff review with public-perspective examination, and integration. |  | [request] |
| `/nw-design` | Designs system architecture with C4 diagrams and technology selection. Use when defining component boundaries, choosing tech stacks, or creating architecture documents. | [nw-ddd-architect](../agents/nw-ddd-architect.md), [nw-platform-architect](../agents/nw-platform-architect.md), [nw-solution-architect](../agents/nw-solution-architect.md), [nw-system-designer](../agents/nw-system-designer.md) | [component-name] - Optional: --residuality --paradigm=[auto|oop|fp] |
| `/nw-devops` | Designs CI/CD pipelines, infrastructure, observability, and deployment strategy. Use when preparing platform readiness for a feature. | [nw-platform-architect](../agents/nw-platform-architect.md) | [deployment-target] - Optional: --environment=[staging|production] --validation=[full|smoke] |
| `/nw-diagram` | Generates C4 architecture diagrams (context, container, component) in Mermaid or PlantUML. Use when creating or updating architecture visualizations. | [nw-solution-architect](../agents/nw-solution-architect.md) | [diagram-type] - Optional: --format=[mermaid|plantuml|c4] --level=[context|container|component] |
| `/nw-discover` | Conducts evidence-based product discovery through customer interviews and assumption testing. Use at project start to validate problem-solution fit. | [nw-product-discoverer](../agents/nw-product-discoverer.md), [nw-product-owner](../agents/nw-product-owner.md) | [product-concept] - Optional: --interview-depth=[overview|comprehensive] --output-format=[md|yaml] |
| `/nw-discuss` | Clarifies product intent and records jobs, journeys, outcomes and visible increments through nwdes. | [nw-product-owner](../agents/nw-product-owner.md) | [product question or outcome] |
| `/nw-distill` | Compiles permanent architecture and value authority into an executable public oracle for automatic delivery. | [nw-acceptance-designer](../agents/nw-acceptance-designer.md) | [requested outcome] |
| `/nw-diverge` | Generates 3-5 divergent design directions through JTBD analysis, competitive research, structured brainstorming, and taste evaluation before convergence. | [nw-diverger](../agents/nw-diverger.md), [nw-diverger-reviewer](../agents/nw-diverger-reviewer.md), [nw-product-owner](../agents/nw-product-owner.md), [nw-researcher](../agents/nw-researcher.md) | [feature-id] - Optional: --work-type=[new-product|brownfield|pivot] |
| `/nw-document` | Creates evidence-based documentation following DIVIO/Diataxis principles. Use when writing tutorials, how-to guides, reference docs, or explanations. | [nw-documentarist](../agents/nw-documentarist.md), [nw-documentarist-reviewer](../agents/nw-documentarist-reviewer.md), [nw-researcher](../agents/nw-researcher.md), [nw-researcher-reviewer](../agents/nw-researcher-reviewer.md) | [topic/component] - Optional: --type=[tutorial|howto|reference|explanation] --research-depth=[overview|detailed|comprehensive|deep-dive] |
| `/nw-forge` | Creates new specialized agents using the 5-phase workflow (ANALYZE > DESIGN > CREATE > VALIDATE > REFINE). Use when building a new AI agent or validating an existing agent specification. | [nw-agent-builder](../agents/nw-agent-builder.md) | [agent-name] - Optional: --type=[specialist|reviewer|orchestrator] --pattern=[react|reflection|router] |
| `/nw-hotspot` | Git change frequency hotspot analysis — find the most-changed files in your codebase |  | [--top=N] [--since=6m] [--json] [--rank report.md] [--detail file] |
| `/nw-mikado` | [EXPERIMENTAL] Complex refactoring roadmaps with visual tracking | [nw-software-crafter](../agents/nw-software-crafter.md) | [refactoring-goal] - Optional: --complexity=[simple|moderate|complex] --visualization=[tree|graph] |
| `/nw-mode-select` | Choose or change the human collaboration mode without runtime gates. |  | [interactive | final human review | full delegation] [scope] |
| `/nw-mutation-test` | Runs a standalone mutation probe, disabled by default, over a named production delta or the explicit nightly production delta. |  | [--delta <base>...<head> | --nightly-delta] [--threshold 80] |
| `/nw-optimize-tests` | Minimizes a test portfolio while preserving observable behavior and mutation value. |  | [test scope] |
| `/nw-refactor` | Applies the Refactoring Priority Premise (RPP) levels L1-L6 for systematic code refactoring. Use when improving code quality through structured refactoring passes. | [nw-software-crafter](../agents/nw-software-crafter.md) | [target-class-or-module] - Optional: --level=[1-6] --method=[extract|inline|rename|move] --scope=[method|class|module] |
| `/nw-research` | Gathers knowledge from web and files, cross-references across multiple sources, and produces cited research documents. Use when investigating technologies, patterns, or decisions that need evidence backing. | [nw-researcher](../agents/nw-researcher.md) | [topic] - Optional: --research_depth=[overview|detailed|comprehensive|deep-dive] --skill-for=[agent-name] |
| `/nw-review` | Routes an actual artifact or candidate diff to the matching independent reviewer. |  | [owner] [repository-relative artifact or diff identity] |
| `/nw-root-why` | Root cause analysis and debugging | [nw-troubleshooter](../agents/nw-troubleshooter.md) | [problem-description] - Optional: --depth=[3|5|7-whys] --output=[text|diagram|report] |
| `/nw-spike` | [DEPRECATED — use /nw-design with analysis focus instead] Runs a timeboxed spike to validate one core assumption before DESIGN. Use after DISCUSS when the feature involves a new mechanism, performance requirement, or external integration. | [nw-software-crafter](../agents/nw-software-crafter.md), [nw-ux-designer](../agents/nw-ux-designer.md) | [feature-description] - Example: "wave-matrix -- derive feature status from pytest + filesystem" |
