# nw-diagram

Generates accessible, legible C4 architecture diagrams (context, container, component) in Mermaid or PlantUML under 12 checkable rules. Use when creating, updating or reviewing architecture diagrams, or when documents.readable_brief is enabled.

**Used by:** [nw-documentarist](../agents/nw-documentarist.md), [nw-solution-architect](../agents/nw-solution-architect.md), [nw-solution-architect-reviewer](../agents/nw-solution-architect-reviewer.md)
