# nw-rigor

Use when the user wants to see or change how much rigor a project gets (review rounds, examine level), which provider/model a role uses, or whether readable documents are written. The LLM reads the current settings, asks only the missing choices in plain words, and runs `nwave-ai rigor` or `nwave-ai model set` itself. Never derives a model from a competence label.

**Used by:** [nw-nwave-buddy](../agents/nw-nwave-buddy.md)
